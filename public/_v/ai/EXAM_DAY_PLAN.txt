JO QUESTION NAVO J HOY (koi match na thay)
  * Sauthi nazdiki program lo, tema DATA badlo (facts, grid, rules) - logic nahi.
  * Pehla ek nano chalto version run karo (error vagar), pachi data vadharo.
  * Prolog ma error aave to:  facts nu "." (full stop) lakhyu che? Bracket / comma barabar che?
    ':- initialization(main).' file ni upar j rakho.
  * Python ma IndentationError aave to space/tab mix na karo (4 space j vapro).

VIVA ma POOCHE TO (1 line ma)
  BFS = level by level (queue), shortest path (equal cost) | DFS = ek rasto ander sudhi (stack/recursion) |
  DLS = DFS with depth limit | A* = f = g + h (cost + heuristic) optimal | Greedy = faqat h, fast pan optimal nahi |
  CSP = variables + domains + constraints, backtracking | Minimax = max/min player, Alpha-Beta = nakamu branches kapi nakhe (ocha nodes) |
  Forward chaining = facts thi goal | Backward chaining = goal thi facts | Frame = slots + inheritance |
  Expert system = knowledge base + inference engine + user interface | Prolog = facts, rules, queries; backtracking automatic.
